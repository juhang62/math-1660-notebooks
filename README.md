# MATH 1660 analysis notebooks

Three Python notebooks for MATH 1660 (Fall 2026), one for each analysis question about the class's campus vampire game. Each runs in Google Colab and uses only the Python standard library and matplotlib.

| Notebook | Question | Open in Colab |
|---|---|---|
| `q1-do-some-vampires-bite-more.ipynb` | Do some vampires bite much more than others? The shuffle test on the number of biters, and the likelihood-ratio test of the Poisson model against the negative binomial | [open](https://colab.research.google.com/github/juhang62/math-1660-notebooks/blob/main/q1-do-some-vampires-bite-more.ipynb) |
| `q2-converts-and-roots.ipynb` | Do converts bite as often as the vampires the walkers recruited? The permutation test over the lists of bite counts that could have produced the chains | [open](https://colab.research.google.com/github/juhang62/math-1660-notebooks/blob/main/q2-converts-and-roots.ipynb) |
| `q3-when-bites-happen.ipynb` | When in a vampire's lifetime does the biting happen? An exact test of whether bites fall at random times in the lifetime, with a check by simulation | [open](https://colab.research.google.com/github/juhang62/math-1660-notebooks/blob/main/q3-when-bites-happen.ipynb) |

## How to use them

1. Open a notebook with its *open* link above.
2. Make your own copy before changing anything: *File*, then *Save a copy in Drive*. Changes to the copy opened from this page are not saved.
3. Run the cells in order, from the top.

## No data here

The notebooks hold no data from the game and no link to it. Each opens in **practice mode**: it makes up an export for an imaginary game and runs every step on that. A team reads the game's data only after its analysis plan is submitted, by pasting the export link it is then given into Step 1. Do not save or share a copy of a notebook that has the link in it, or that was run on the game's data.

## Where the notebooks come from

The notebooks are built by scripts in the course's private repository and copied here automatically whenever they change. A change made directly in this repository is overwritten by the next copy.
